# Как собрать APK только с телефона

В проект добавлен GitHub Actions workflow `.github/workflows/build-apk.yml`. Он собирает APK в облаке, поэтому Android Studio и компьютер не нужны. Нужен аккаунт GitHub и браузер на телефоне.

1. Создайте новый репозиторий на github.com (например, `ime-cache-cleaner`).
2. Загрузите в репозиторий файлы проекта и папку `.github/workflows/build-apk.yml` с сохранением структуры. Если мобильный интерфейс не позволяет загрузить папку, используйте GitHub в браузере в режиме «Версия для ПК».
3. Откройте вкладку **Actions** и выберите **Build iMe Cache Cleaner APK**.
4. Нажмите **Run workflow** и дождитесь зелёной галочки.
5. Откройте завершённый запуск workflow, пролистайте вниз до **Artifacts** и скачайте `iMe-Cache-Cleaner-debug`.
6. Распакуйте ZIP артефакта и установите `app-debug.apk`. Android может попросить разрешить установку из этого источника.

Важно: это debug APK, не опубликованный в Google Play. Для работы очистки нужен установленный и запущенный Shizuku с выданным разрешением. Команда не должна удалять данные приложения; если система не поддерживает `--cache-only`, очистка должна завершаться безопасно.
